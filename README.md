## 🛠️ Step-by-Step Deployment Guide

Follow these exact steps to push this website to your **GitHub** account, host it for free on **Vercel**, and connect your custom domain **akhileswarchowdary.com**.

---

### Step 1: Create a GitHub Repository and Upload Files

#### Option A: Via GitHub Web Browser (Easiest & Fastest — No Git Installation Needed!)
1. Log in to [github.com](https://github.com).
2. Click the **`+`** icon in the top right corner and select **"New repository"**.
3. Repository name: `akhileswar-portfolio` (or `akhileswarchowdary.com`).
4. Set visibility to **Public**.
5. Do **NOT** check "Add a README file" (we already have one).
6. Click **"Create repository"**.
7. On the setup screen, click the link: **"uploading an existing file"**.
8. Open your folder: `c:\Users\akhil\OneDrive\Desktop\Akhileswar Personal Website`.
9. Select all files and folders (`index.html`, `vercel.json`, `sitemap.xml`, `robots.txt`, `README.md`, and the `assets` folder) and drag-and-drop them into the browser window.
10. Click **"Commit changes"**. Your code is now safely on GitHub!

#### Option B: Using GitHub Desktop
1. Download & install [desktop.github.com](https://desktop.github.com).
2. Click **File -> Add Local Repository**.
3. Choose `c:\Users\akhil\OneDrive\Desktop\Akhileswar Personal Website`.
4. Click **Publish repository** to push directly to your GitHub account.

---

### Step 2: Deploy to Vercel (100% Free)

1. Go to [vercel.com](https://vercel.com) and click **Sign Up** (or Log In) using your **GitHub account**.
2. On your Vercel Dashboard, click **"Add New..."** -> **"Project"**.
3. Under **Import Git Repository**, you will see your new repository (`akhileswar-portfolio`).
4. Click **"Import"** next to it.
5. In the configuration screen:
   - **Project Name:** `akhileswarchowdary` (or keep default).
   - **Framework Preset:** `Other` (Static HTML).
   - **Root Directory:** `./`
6. Click **"Deploy"**.
7. Within 15 seconds, your site will be live on a free Vercel URL (e.g. `akhileswarchowdary.vercel.app`) with free global CDN and SSL!

---

### Step 3: Connect Your Custom Domain (`akhileswarchowdary.com`)

1. In your **Vercel Project Dashboard**, click on **"Settings"** (tab at the top).
2. Click on **"Domains"** in the left menu.
3. In the input box, type:
   `akhileswarchowdary.com`
   and click **"Add"**.
4. Vercel will recommend adding both `akhileswarchowdary.com` and `www.akhileswarchowdary.com`. Select that recommended option.
5. Vercel will display the exact **DNS Records** you need to add at your domain registrar (GoDaddy, Namecheap, Hostinger, Cloudflare, or Google Domains):

| Type  | Name / Host | Value / Target         | TTL        |
|-------|-------------|------------------------|------------|
| **A** | `@` (or leave blank) | `76.76.21.21`          | Automatic / 3600 |
| **CNAME** | `www`       | `cname.vercel-dns.com` | Automatic / 3600 |

6. Log in to your domain registrar, navigate to **Manage DNS**, and add the two records above.
7. Return to Vercel and click **"Refresh"**. Once verified, Vercel will automatically generate a free SSL certificate (HTTPS), and your website will be live globally at **https://akhileswarchowdary.com**!
